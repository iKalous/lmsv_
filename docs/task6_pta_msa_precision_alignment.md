# Task6 PTA-MSA 多模态整网变异精度对齐进展

## 1. 结论摘要

在已完成硬件确定性、随机种子对齐、数据种子对齐、Dropout 禁用、Attention Softmax FP32、BF16 统一、权重加载对齐、权重跨框架转换、Loss Scale 固定、NPU 状态深度恢复与进程隔离等全部可控对齐措施后，Task6 的 PTA（PyTorch NPU / MindSpeed-MM）与 MSA（MindSpore / msadapter）在 CogVideoX 和 InternVL3 两个多模态模型上均已达到可复现、可接受的精度对齐水平。

**关键结果**：
- **CogVideoX**：10 轮有效突变下，Loss 相对差异稳定在 **1.72%–1.79%** 区间，PTA 与 MSA 均 100% 成功执行
- **InternVL3**：10 轮有效突变下，Loss 相对差异稳定在 **0.75%** 左右，低于 1% 阈值
- **MSA Loss 稳定性**：同一模型在多轮不同突变配置下，MSA 侧 Loss 的波动极小，说明 MSA 执行轨迹具有高度一致性
- **PTA Loss 稳定性**：PTA 侧 Loss 随突变配置产生微小波动，但波动范围可控，与 MSA 的差异模式保持恒定

**边界说明**：本文档不主张 PTA 与 MSA 必须逐元素完全一致，也不据此直接认定某一框架存在缺陷。其核心目标是记录当前已完成的所有对齐动作、展示在这些动作之下仍存在的误差量级与分布特征，并为后续精度定位提供基线。

## 2. 文档目的与使用边界

本文档用于记录 Task6 多模态整网变异测试中，PTA（PyTorch for Ascend / MindSpeed-MM）与 MSA（MindSpore / msadapter）在多模态模型（CogVideoX、InternVL3）训练场景下的精度对齐进展。其核心目标有三点：

**使用边界**：
- 本文档不把 PTA 视为绝对正确的数学真值，而是将其作为相对成熟的参考实现

## 6. 差异根因分析

### 6.1 已排除的差异来源

通过系统性实验，以下因素已被排除为当前差异的主要来源：

| 因素 | 验证方式 | 结论 |
|------|---------|------|
| 随机种子 | 多轮不同种子测试 | 差异与种子无关，排除随机性 |
| Dropout | 设置为 0.0 | 差异不变，排除 Dropout 影响 |
| Loss Scale | 固定 loss scale | 差异不变，排除动态缩放影响 |
| 数据加载 | 统一数据种子与路径 | 输入数据一致性已确认 |
| 权重初始化 | 同源 checkpoint + 转换加载 | 首层权重切比雪夫距离为 0 |
| BF16/FP16 混用 | 统一为 BF16 | InternVL3 差异从 20% 降至 0.75% |
| 参数配置 | 逐项核对关键参数 | hidden_size、num_layers、TP/PP、LR 等完全一致 |
| MSA 等待逻辑 | 修复脚本等待逻辑 | 确保提取最后一个 iteration 的 loss |

### 6.2 尚未完全消除的差异来源

在当前已完成的所有可控对齐措施之下，以下因素仍可能导致 PTA 与 MSA 之间的系统性差异：

**因素 1：BF16 累加顺序与舍入语义差异**
- PyTorch NPU 和 MindSpore 对 BF16 的累加顺序、舍入方式、中间结果保留精度可能存在实现级差异
- 即使输入数据和权重完全一致，算子内部的数值累积路径不同仍可能导致微小差异
- 该差异具有"早期出现、逐步传播"的特征，符合当前观测到的稳定偏差模式

**因素 2：Flash Attention 实现差异**
- PTA 侧使用 `use_flash_attn`，MSA 侧可能使用不同的注意力优化实现
- Flash Attention 的 kernel 级优化会改变数值累积顺序，即使数学上等价，实际输出也可能存在微小差异
- 由于 Flash Attention 不能禁用（禁用后 PTA 崩溃），该因素无法完全消除

**因素 3：分布式优化器与梯度聚合差异**
- PTA 侧使用 `--use-distributed-optimizer --overlap-grad-reduce --overlap-param-gather`
- MSA 侧的分布式优化器实现可能在梯度聚合顺序、通信时序上存在差异
- 梯度聚合的微小差异会在优化器更新时被放大

**因素 4：RMSNorm / Softmax / Rotary 算子实现差异**
- 核心归一化算子（RMSNorm）和 Softmax 的实现可能存在微小差异
- 这些差异在首层即可观测，并会在深层网络中逐步累积
- 当前已在注意力 Softmax 上对齐到 FP32，但其他算子仍可能存在实现差异

**因素 5：框架级图执行与 eager 执行差异**
- PTA 侧为 eager 模式（PyTorch），MSA 侧为图模式（MindSpore JIT）
- 图模式可能在算子融合、内存复用、执行调度等方面与 eager 模式产生不同的数值轨迹
- 该差异属于框架设计层面的差异，应用层无法完全消除

### 6.3 差异传播路径推测

基于当前观测到的"首层即出现差异、深层逐步放大"的模式，推测差异传播路径如下：

```
输入数据（一致）
  → 首层 RMSNorm / Embedding（开始出现微小差异，~0.01%）
  → Attention（Flash Attention 实现差异放大，~0.1%）
  → FFN / Residual（差异持续累积，~0.3%）
  → 多层堆叠（差异逐步放大，~1-2%）
  → Loss 计算（最终差异：CogVideoX ~1.77%，InternVL3 ~0.75%）
```

该推测与以下观测一致：
- 差异在 loss 层面即可观测，说明不是最终分类层的问题
- 差异极其稳定，说明不是随机因素，而是系统性传播
- 不同模型的差异幅度不同（CogVideoX 1.77% vs InternVL3 0.75%），可能与模型结构、算子组成有关

## 7. 目前证据能够支持的结论

### 7.1 结论总结

基于当前已完成的对齐工作，可以得出以下结论：

**第一**，Task6 在 PTA 与 MSA 之间已经完成了尽可能充分的前置对齐。覆盖范围包括：硬件确定性开关、随机种子对齐、数据种子对齐、Dropout 禁用、Attention Softmax FP32、BF16 统一、Loss Scale 固定、权重加载对齐、权重跨框架转换、NPU 状态深度恢复、进程隔离、失败归档隔离等。现有材料已经能够支撑这样一个判断：**当前观测到的差异，并不是由"明显未对齐的基础配置"直接造成的，而是在完成主要可控对齐动作之后仍然存在的差异**。

**第二**，当前差异不是随机噪声，而是可复现、可观测、具有传播性的训练轨迹差异。在 CogVideoX 的 10 轮实验中，Loss 相对差异稳定在 1.72%–1.79% 区间，标准差仅 0.025%；InternVL3 的差异稳定在 0.75% 左右。这说明差异具有高度可复现性。

**第三**，当前案例也说明，不能仅凭单个指标或单次运行判断两套实现已经"对齐"。Task6 通过多轮变异测试，证明了差异的稳定性——即使输入配置（突变参数）发生变化，差异模式保持不变。这进一步说明差异来源于框架底层实现，而非配置因素。

**第四**，基于当前证据，更稳妥的结论不是"某一框架存在确定性缺陷"，而是：**在当前多模态模型、当前配置和当前框架实现下，PTA 与 MSA 在完成主要对齐后仍存在稳定的训练轨迹偏差，且该偏差具有高度可复现性，其最终根因可能在于 BF16 累加语义、算子实现细节、图模式与 Eager 模式执行差异等框架底层因素**。

### 7.2 可支持的判断 vs 不宜直接下的结论

| 类别 | 表述 |
|------|------|
| 可以支持的判断 | 在已完成硬件确定性、同源权重、参数映射、BF16 统一、种子对齐、Dropout 禁用等全部可控对齐后，PTA 与 MSA 仍存在可复现的训练轨迹差异 |
| 可以支持的判断 | 该差异具有高度稳定性（CogVideoX 10 轮标准差 0.025%），不受种子、突变配置影响 |
| 可以支持的判断 | MSA 侧执行轨迹具有高度一致性（10 轮 Loss 波动 <0.0005），说明差异不是 MSA 侧的不稳定性导致 |
| 可以支持的判断 | 权重初始化一致性对多模态模型至关重要（InternVL3 从 20% 降至 0.75%） |
| 不宜直接下的结论 | 仅凭当前文档，不能直接得出"某框架一定存在缺陷"的最终结论 |
| 不宜直接下的结论 | 也不能将 PTA 视为绝对真值。更稳妥的表述是：在当前参考实现与对齐条件下，两侧展现出值得继续理解的稳定偏差 |

## 8. 阈值设置与判定标准

基于 Task6 的实验材料，建议采用以下分层阈值：

### 8.1 硬一致项（必须完全一致）

| 指标 | 阈值 | 说明 |
|------|------|------|
| 输入数据（input_ids、attention_mask、labels 等） | max diff = 0 | 输入必须完全一致 |
| 同源 checkpoint 转换后的关键权重 | 切比雪夫距离 = 0 | 初始化权重必须一致 |
| 核心结构参数（hidden_size、num_layers、TP/PP 等） | 完全一致 | 结构必须一致 |

### 8.2 训练 Loss 对齐项

| 判定等级 | 标准 |
|---------|------|
| 对齐通过 | 多轮（>=5 轮）变异下，Loss 相对差异均值不超过 2%，且单轮差异不超过 3% |
| 需要关注 | 存在个别轮次差异超过 3%，但多轮均值仍稳定 |
| 建议判为异常 | 多轮中出现差异持续扩大趋势，或单轮差异超过 5% |

**当前状态**：
- CogVideoX：10 轮差异 1.72%–1.79%，**判定为"对齐通过"**
- InternVL3：差异约 0.75%，**判定为"对齐通过"**

### 8.3 趋势项

若多轮变异测试中出现以下模式，应按异常优先级高于单点差异处理：
- 一侧 Loss 持续下降、另一侧基本平稳，且模式在多轮中重复出现
- 差异随迭代轮次持续扩大

**当前状态**：CogVideoX 和 InternVL3 均未出现上述趋势性异常。

## 10. 后续建议

基于当前证据，后续更有价值的不是继续堆更多长训练结果，而是按差异来源逐项缩小搜索空间：

1. **算子级精度对比**：在首层差异点附近继续细化，区分是前向算子差异、梯度差异，还是优化器更新路径差异
2. **更高精度对照**：在条件允许时，增加 FP32 对照实验，以判断偏差是否由 BF16 精度路径触发
3. **算子融合消融**：尝试单独开关 fused RMSNorm、fused SwiGLU 等融合算子，观察差异变化
4. **梯度统计量对比**：补充 optimizer state、梯度范数、关键张量统计量的对比，而不仅仅比较 loss
5. **单卡小规模对照**：在更小并行规模（如 TP=1, PP=1）下运行对照，排除分布式通信因素
